# UI Helper v0.2.1

## Changes

- Behavior-preserving refactor of annotations, DOM restoration, Markdown export,
  transform controls, panel connections, recording workflows and shared styles.
- Preserve public APIs, message payloads, permissions and existing user workflows.
  No framework migration or third-party dependency upgrade.
- Expand automated coverage from 9 to 36 tests, repair stale browser test paths,
  and document runtime boundaries and regression checks.

## Install / update

1. Download `ui-helper-v0.2.1-chrome.zip` and unzip it.
2. Open `chrome://extensions` and enable **Developer mode**.
3. Click **Load unpacked** and select the extracted `ui-helper-v0.2.1-chrome` folder.
4. Pin UI Helper, open your page, and click the extension icon.

To update, replace the previous extracted files and reload both the extension and
inspected page. Chrome/Edge 116+ is required. This is a GitHub release, not a Chrome
Web Store publication. Authorize a project directory when first opening recording
options to save GIFs under `.ui-helper/recordings/`.

## Validation

- 36 automated tests, workspace type checks and production build passed.
- Six real-extension suites passed in Ego Lite/Chromium 152 on macOS: editing,
  save/cancel/restore, all resize handles, zoom 50/100/200%, clipboard, real Window
  and Area GIF capture, worker restart, tab isolation and native panel lifecycle.
- Element matrix: **20 passed, 1 known skip, 0 failed**. The `.profile-copy` parent
  remains unselectable where its children cover its entire hit area.
- Actual generated GIF metadata and file retention after deletion were verified.
- The version-only release bump retains the exact content bundle tested natively
  under the pre-release 0.2.0 manifest (SHA-256 recorded in the test report).
- ZIP integrity and packaged manifest version were checked before publication.

See [native regression details](../../tests/native-refactor-results.md) and
[refactor results](../../tests/refactor-results.md). These checks do not claim
exhaustive website, OS permission-error or minimum-browser-version coverage.
